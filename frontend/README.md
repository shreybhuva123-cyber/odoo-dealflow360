# DealFlow360 — Frontend Architecture

Next-generation Intelligent Quotation, Approval & Fulfillment Engine for Odoo Hackathon.

## Stack
- **React 18 + TypeScript + Vite**
- **Tailwind CSS + shadcn/ui design tokens**
- **React Router v6** (Nested routes, dual Internal/CustomerPortal layouts)
- **TanStack Query (React Query v5)** (Server state management)
- **Zustand** (Auth, UI, and Workspace stores)
- **React Hook Form + Zod** (Validation)
- **Recharts** (Analytics & pipeline visualization)
- **Lucide React** (Clean enterprise iconography)

## Getting Started
```bash
npm install
npm run dev
```
Runs at `http://localhost:3000`.
